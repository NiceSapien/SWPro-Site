How to Install Sketchware Pro

  1. 1
    Locate the APK file Open your browser's Downloads tab or your device's Files app and find app-release.apk(sketchware-pro.apk if downloaded from the mirror).
  2. 2
    Allow Unknown Sources Tap the APK file. If prompted, open Settings and toggle on Allow from this source for your browser or file manager.
  3. 3
    Complete Installation Go back and tap Install. If Google Play Protect shows a prompt for sideloaded apps, tap More details → Install anyway.
  4. 4
    Grant Storage Permissions Launch Sketchware Pro and allow file/storage access so the app can compile APKs and save your projects.
